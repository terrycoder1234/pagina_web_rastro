# Rastro

Estructura inicial de una pagina web estatica.

## Estructura

- `index.html`: pagina principal y contenido semantico.
- `css/styles.css`: estilos, variables y responsive mobile.
- `js/main.js`: interacciones del menu movil.
- `assets/`: imagenes, iconos, fuentes y otros recursos.

## Vista local

Desde esta carpeta, ejecuta:

```bash
python3 -m http.server 8000
```

Despues abre <http://localhost:8000> en el navegador.
